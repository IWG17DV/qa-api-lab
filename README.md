# Лабораторна робота № 5 — Тестування REST API

Навчальний сервіс замовлень реалізовано на Express. Варіант 10 додає
`GET /admin/orders`: адміністратор отримує замовлення всіх користувачів,
звичайний користувач — `403 Forbidden`.

## Запуск

```sh
npm install
npm test
```

Для перевірки колекції Postman через Newman запустіть сервіс в одному терміналі
та Newman в іншому:

```sh
npm start
npm run test:newman
```

Колекція створює замовлення Bob, перевіряє перегляд усіх замовлень адміністратором
і відмову звичайному користувачу. Результат Newman зберігається у
`newman-results.xml`.

## Тестові облікові записи

Облікові записи задані для локальної лабораторної: `alice@example.com` та
`bob@example.com` із паролем `Secret123`; `admin@example.com` із паролем
`Admin123`. Дані та токени зберігаються в пам’яті окремого екземпляра застосунку.

## Покриття

Supertest-перевірки охоплюють HTTP-коди, JSON Schema з
`additionalProperties: false`, значення відповідей, заголовки та побічні ефекти.
Також перевіряються параметризована валідація замовлення, авторизація, доступ до
чужого ресурсу, видалення, адміністраторський список і контроль витоку `ownerId`.
